# Image Service

This service has all the related pacakages and orquestation for the image uploading.

## This Service includes

- Bucket
  - Logic for CRUD operation on a S3 like bucket
- Images
  - Logic for image optimization
  - Output class that define estructure, open for extra methods or changes in them

## Getting started

Is important to check for the .env.example to provide the correct enviroment for this service. Also check the config file for any further customisation of it.
